# NEON SNAKE 3D

一个零依赖的 3D 贪吃蛇 H5 小游戏。没有用 three.js，也不加载任何 CDN 资源——渲染器、几何体、着色器和玩法全部手写在同一个文件里，打开就能玩。

## 直接玩

打开 `dist/snake-3d.html` 即可（单文件、可离线、可直接丢到任意静态托管）。

## 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 转向 | 方向键 / WASD / HJKL | 滑动屏幕或右下虚拟方向键 |
| 开始 / 暂停 | 空格 | 点击按钮 |
| 重开 | R | 结束页按钮 |
| 切换视角 | C | 右上 🎥 |

共三种视角：跟随（默认）、全景、追尾。

## 玩法

- 17 × 17 棋盘，撞墙或咬到自己即结束。
- 普通能量球 +10 分；金色能量球 +30 分（约 18% 概率）。
- 每吃一个球，蛇速提升一档，最快约 78ms / 步。
- 最高分写在 `localStorage`（异常环境下自动降级，不影响游戏）。

## 工程结构

```
src/index.html      页面骨架、HUD、覆盖层、样式
src/game.js         迷你 WebGL 渲染器 + 全部玩法（约 1000 行）
build.js            把 HTML 与 JS 合并成单文件产物
dist/snake-3d.html  构建产物（唯一需要分发的文件）
test/               逻辑测试、构图测试、产物测试、CPU 光栅化预览
preview/            CPU 光栅化出的效果图（横屏 / 竖屏）
```

## 渲染实现

- WebGL1 + 自写顶点/片元着色器：Lambert 主光 + 补光 + 菲涅尔边缘光 + 距离雾。
- 棋盘、围栏、底座合并为一个静态网格，一次 draw call 画完（约 7.4k 三角形）。
- 蛇身按格插值做刚性平移，转身、加速都不会跳帧；移动端按屏幕比例自动拉远相机。
- 吃到食物有粒子爆裂、镜头轻震和合成音效（WebAudio，无音频文件）。

## 开发

```bash
npm test        # 玩法 + 构图 + 产物三组测试
npm run build   # 重新生成 dist/snake-3d.html
npm run preview # 构建并起本地静态服务（localhost:8080）
```

测试在无浏览器环境下用桩 WebGL 跑真实帧循环；`test/render-preview.js` 会用与着色器相同的公式做 CPU 光栅化，输出 `preview/*.png` 用于人工检查画面。
